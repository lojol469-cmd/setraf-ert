🎯 MODÈLES IA - TÉLÉCHARGEMENT AUTOMATIQUE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Les modèles IA NE SONT PAS dans l'image Docker.
Ils seront téléchargés AUTOMATIQUEMENT au premier démarrage.

Source: HuggingFace Hub (https://huggingface.co)

Modèles téléchargés:
  📦 SentenceTransformer    88 MB      ~1 min
  📦 CLIP                   600 MB     ~3 min
  📦 Mistral-7B (opt)       14 GB      ~15 min

Après le premier démarrage, les modèles sont EN CACHE.
Redémarrages suivants: <30 secondes ⚡

🐳 DÉMARRAGE DOCKER COMPOSE (Local/Test)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

cd /home/belikan/KIbalione8/SETRAF

# 1. Démarrer
docker-compose -f docker-compose.production.yml up -d

# 2. Suivre les logs (téléchargement des modèles)
docker logs -f setraf-production

# 3. Ouvrir l'application
#    http://localhost:8504

# 4. Arrêter
docker-compose -f docker-compose.production.yml down

☸️  DÉMARRAGE KUBERNETES (Production)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

cd /home/belikan/KIbalione8/SETRAF/kubernetes

# 1. Configurer les secrets
nano configmap.yaml
# Remplacer HF_TOKEN et TAVILY_API_KEY (en base64)

# 2. Déployer
./deploy-k8s.sh apply

# 3. Vérifier l'état
kubectl get all -n setraf

# 4. Suivre les logs
kubectl logs -n setraf -l app=setraf -f

# 5. Obtenir l'URL
kubectl get svc -n setraf
